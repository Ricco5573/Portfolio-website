Project Overview

Though we struggled with monogame for a bit, we got quite a bit done, though its not quite in the state i hoped for. I worked on the upgrade system, which i ended up doing with a JSON file. By adding more objects to the JSON file you create an upgrade. Which will automatically be added to the game.

All upgrades scale with one another linearly, so some crazy combinations can be made.
