Project Overview

Though we struggled with monogame for a bit, we got quite a bit done, though its not quite in the state i hoped for. I worked on the upgrade system, which i ended up doing with a JSON file. By adding more objects to the JSON file you create an upgrade. Which will automatically be added to the game.

The upgrade system is quite a beast, so lemme explain my code here. 


public class Upgrade : SpriteGameObject
{
    public string name {get; set;}
    public string description {get; set;}
    public JsonObject[] modifications {get; set;}
    public List mods{get; set;}
    public int spriteID {get; set;}
    
    public Upgrade(string name, string description, JsonObject[] modifications,
    int spriteID) : base("Images/Upgrade", 0, " ", 0)
    {
        this.modifications = modifications;
        this.name = name;
        this.description = description;    
        this.spriteID = spriteID; 
        mods = new List();
        for(int i = 0; i < modifications.Length; i++){
            Modification mod = JsonSerializer.Deserialize(modifications[i]);
            mods.Add(mod);
        }
    }

An upgrade consists of a name, a description which will show when hovered over. It has an ID for a sprite which we didnt end up using, but would be used to show different rarities of upgrades. then, it has mods, or modifications. each modification is a change to a stat. 


public class Modification
  {
      public int variableId {get; set;}
      public int multiplicative {get; set;}
      public float mod {get; set;}

      public Modification(int variableId = 1, int multiplicative = 1, float mod = 0.0f){
          this.variableId = variableId;
          this.multiplicative = multiplicative;
          this.mod = mod;
      }

Each mod has a variableId, that being the ID of the stat they are modifying. an int for multiplicativity, where 0 is yes, and 1 is no (because a JSON doesnt allow booleans). And lastly, the modification itself. That being a full number. In the end, a full upgrade would look something like this: 

                  {
  "name": "More powder",
  "description": "Deal 1 extra damage, bullets move 50% faster",
  "modifications": [
      {
        "variableId": 4,
        "multiplicative": 0,
        "mod": 1.5
      },
      {
        "variableId": 7,
        "multiplicative": 1,
        "mod": 1
      }
    ],
    "spriteIndex": 1
  },

After this, the upgrades go into slots, and simply put, everytime the player shoots, it will loop through all equipped upgrades, and apply them to the projectile. Now to be fair, there mightve been better ways to do it than a switch case with every ID in it. But this was a solution understandable by my teammates, which allowed them to expand it as well. 


  foreach(UpgradeSlot up in upgradeSlots){
     if(up != null && up.GetUpgrade() != null){
      List mods = up.GetUpgrade().GetMods();
      foreach(Modification mod in mods){
          int id = mod.GetVarId();
          float change = mod.GetMod();
          switch(id){
             case 0: adjFireRate  = mod.GetMult() ? adjFireRate * change : 
             adjFireRate + change;
             break;
             case 1: adjProjectiles = mod.GetMult() ? (int)(adjProjectiles * change) : 
             (int)(adjProjectiles + change);
             break;
             case 2: adjSpread = mod.GetMult() ? (int)(adjSpread * change) : 
             (int)(adjSpread + change);
             break;
             case 3: adjMoveSpeed = mod.GetMult() ? adjMoveSpeed * change : 
             adjMoveSpeed + change;
             break;
             case 4: adjProjectileSpeed = mod.GetMult() ? adjProjectileSpeed * change : 
             adjProjectileSpeed + change;
             break;
             case 5: tempExplosive = change == 1;
             break;
             case 6: adjUpgradeChance = mod.GetMult() ? adjUpgradeChance * change : 
             adjUpgradeChance + change;
             break;
             case 7: tempProjectileDamage = mod.GetMult() ? (int)(tempProjectileDamage * change) : 
             (int)(tempProjectileDamage + change);
             break;
             case 8: adjProjectileSize = mod.GetMult() ? adjProjectileSize * change :
             adjProjectileSize + change;
             break;
         }
     } 
 }
