Apocrypha

A 2d platformer built in javascript. My biggest contribution was a level editor i built.

Live build

Project Overview

The level editor was quite something, i spend most of the project chipping away at it. But as of right now, it somehow still works. Database integration and all! Meaning that you can still make levels, and upload them to the database for others to try out!

Now the editor is quite self explanatory. You place items, which are just copied onto the place you click. When pressing B you start the game, and pressing it again brings you back into the editor mode. Allowing you to quickly test parts of your level. This was done by simply pauzing all physics interactions. When the player is done. They save the map to a JSON. That is done as follows

Each object within the map is reduced to an obj. containing an index for which object it represents, a position, a size, a renderlayer and a spriteIndex. renderlayers allow objects to be used as decoration as well as platforms. It allows items to be placed in the background and foreground, allowing for a fun effect as the player runs between sets of pillars!

From there, the player can give the level a name. After which its uploaded to a database. Which may or may not be down depending on how long from now you try it. Now i know again, that this wasnt the best way to handle the database as im just throwing the entire JSON file on there, given that JSON have a limited size within a standard database. However, considering all im saving is text, the map could reach several tens of thousands of objects before i would come anywhere near the limits of the database. Far faster to run out would be your graphical memory

Which isnt quite a joke, despite my best attempts the game isnt greatly optimized, the amount of sprites weve used, their size and the fact were modifying them makes any CPU crumple. Which is the main problem, rendering is done via the CPU. Though ive attempted to make it render via the GPU, ive so far been unsuccessfull in actually doing it. This also results in quite a large lagspike when first loading into the game.
